# Склейка дорожек кола в цельный файл

## Задача

Кнопка в виджете, которая склеивает записи колов в один файл: две
аудиодорожки (`mic.wav`, `zoom.wav`) сводятся в одну, видео экрана
(`screen.mkv`) прикладывается как есть. Результат — `combined.mp4` в папке кола.

По одному нажатию обрабатываются **все ещё не склеенные** колы по очереди.

## Контекст

Каждый кол пишется в `~/.local/share/health-widget/calls/<id>/`:
- `mic.wav` — микрофон (48 kHz, mono, 16-bit)
- `zoom.wav` — системный звук телемоста (тот же формат)
- `screen.mkv` — видео экрана (NVENC, gst-launch)

Сейчас `screen.mkv` пустой (0 байт) во всех существующих колах — рекордер
экрана падает (`Failed to set pipeline to PAUSED`). Это отдельный баг, в
рамках этой задачи не чиним. Кнопка обязана быть полезной и без видео.

`ffmpeg` установлен в систему (7:8.0.1). Проект шеллит готовые CLI — муск идёт
через `ffmpeg`, а не через новую зависимость.

## Поведение

Кнопка **«🎬 Склеить»** в секции «🎤 Кол» рядом с кнопкой Кол.

По нажатию — фоновый поток перебирает папки колов и склеивает те, что ещё не
склеены:

- Кандидат — числовая папка в `calls/`, у которой есть `mic.wav` или
  `zoom.wav` и **нет** `combined.mp4`.
- Активный кол пропускается (его файлы ещё пишутся).
- Наличие `combined.mp4` = маркер «уже склеено» → пропуск. Идемпотентно.

Для каждого кандидата:
- Видео есть (`screen.mkv` существует и непустой) → видео копируется,
  аудио сводится и кодируется в AAC.
- Видео пустое/нет → аудио-only `combined.mp4`.
- Есть только одна из дорожек → кодируется она одна (без `amix`).
- Нет ни одной аудиодорожки → пропуск (не должно случаться).

Свод двух дорожек: `amix=inputs=2:normalize=0` — суммирование без деления
громкости пополам.

### Команды ffmpeg

Видео + два аудио:
```
ffmpeg -y -i screen.mkv -i mic.wav -i zoom.wav \
  -filter_complex "[1:a][2:a]amix=inputs=2:normalize=0[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac combined.mp4
```

Аудио-only, два трека:
```
ffmpeg -y -i mic.wav -i zoom.wav \
  -filter_complex "[0:a][1:a]amix=inputs=2:normalize=0[a]" \
  -map "[a]" -c:a aac combined.mp4
```

Один трек (видео есть): `-map 0:v -map 1:a -c:v copy -c:a aac`.
Один трек (аудио-only): `-c:a aac`.

Запись сначала во временный `combined.mp4.part`, при успехе `rename` в
`combined.mp4` — чтобы прерванный муск не оставил битый маркер.

## UX и статус

По образцу `screenshot.rs`: статус в `Arc<Mutex<GlueStatus>>`.

```
enum GlueStatus {
    Idle,
    Working { done: usize, total: usize },
    Done(usize),
    Failed(String),
}
```

Строка в секции «🎤 Кол»:
- `Working` → `⧗ склеиваю 2/5…` (жёлтый)
- `Done(0)` → `нечего склеивать` (серый)
- `Done(n)` → `✔ склеено n` (зелёный)
- `Failed(e)` → `✖ e` (красный)

Кнопка `add_enabled(!working, …)` — не запускать второй проход поверх
идущего. Если `ffmpeg` не найден (`which`/spawn упал) → `Failed("нет ffmpeg")`.

## Код

Новый модуль `src/mux.rs`:
- `pub enum GlueStatus { … }`
- `pub fn pending(active_id: Option<i64>) -> Vec<PathBuf>` — папки-кандидаты.
- `fn glue_dir(dir: &Path) -> Result<(), String>` — один кол через ffmpeg.
- `pub fn glue_all(active_id: Option<i64>, status: Arc<Mutex<GlueStatus>>)` —
  спавн потока: перебор `pending`, обновление статуса, финальный `Done`/`Failed`.

`src/main.rs`:
- поле `glue: Arc<Mutex<mux::GlueStatus>>` в состоянии приложения;
- кнопка + строка статуса в `draw_call` (секция «🎤 Кол»);
- `mod mux;`.

Ограничения проекта: без комментариев в коде; строки UI по-русски; ветка
`master`.

## Тесты

- `pending` фильтрует активный кол, уже склеенные (`combined.mp4` есть) и
  папки без аудио; включает папки с `mic.wav`/`zoom.wav` без `combined.mp4`.
  (Юнит-тест на `tempdir` со сфабрикованной структурой папок.)

Реальный муск ffmpeg проверяем вручную на живом коле — в юнит-тестах не
гоняем внешний бинарь.

## Вне рамок

- Починка рекордера экрана (пустой `screen.mkv`).
- Выбор кола из списка / CLI-флаг `--glue` — не сейчас.
- Тонкая настройка громкости/нормализации микса — оставляем `normalize=0`.
