# Авто-кол по речи

## Задача

Кол не должен требовать нажатия кнопки. Как только распознавание выдало речь —
кол начинается сам. Как только речи нет 15 минут — кол закрывается сам.

## Сигнал

Триггер — новый **финальный** текст STT на каналах `🎤 я` (mic) и `🔊 телемост`
(программа). Не уровень звука: финал уже прошёл фильтр галлюцинаций, поэтому
вентилятор, стук по столу и уведомления кол не откроют.

Канал `webmic` не учитывается — он не пишется в дорожки кола.

Тот же сигнал обнуляет таймер тишины: кол живёт, пока приходят финалы.

## Изменения

### `src/transcribe.rs`

`Stt` получает `finals_seq: Arc<AtomicU64>`. Инкремент — в ветке разбора
`{"final": …}` читающего потока, рядом с записью в `fresh` и лог. Геттер
`finals_seq() -> u64`.

### `src/audio.rs`

`AudioMonitor::finals_count() -> u64` — делегат в `Stt`.

### `src/main.rs`

Константа `CALL_SILENCE_LIMIT = Duration::from_secs(15 * 60)`.

Состояние:

```
struct AutoCall {
    seen: u64,
    last_final: Instant,
    paused: bool,
}
```

`seen` инициализируется текущей суммой счётчиков при старте виджета — финалы,
накопленные до запуска, кол не откроют.

Чистое решение (тестируемое отдельно):

```
enum AutoCallAction { Start, End }

fn auto_call_step(
    state: &mut AutoCall,
    finals_total: u64,
    call_active: bool,
    now: Instant,
) -> Option<AutoCallAction>
```

Порядок внутри:

1. `now - last_final >= CALL_SILENCE_LIMIT` → `paused = false` (пауза после
   ручного стопа снимается только 15 минутами тишины, речь её не снимает).
2. `finals_total > state.seen` → `seen = finals_total`, `last_final = now`,
   признак «речь только что была».
3. Решение:
   - нет кола && речь только что была && `!paused` → `Start`;
   - есть кол && `now - last_final >= CALL_SILENCE_LIMIT` → `End`;
   - иначе `None`.

Вызов — в `App::update`, сразу после проверки shutdown, до отрисовки. Сумма
`finals_count()` по `audio.mic` и `audio.zoom`; действия зовут существующие
`start_call()` / `end_call()`.

### Ручной режим

- Стоп кнопкой → `paused = true`: авто-старт молчит, пока не пройдёт 15 минут
  тишины. Иначе кол открылся бы обратно на первой же фразе.
- Старт кнопкой → `paused = false`, `last_final = now`: свежий кол не закроется
  мгновенно и дальше живёт по правилам авто-стопа.

### Телеметрия

В `call.start` / `call.end` добавляется поле `auto` (bool) — видно, кто закрыл
кол: человек или таймер.

## Тесты

Юнит-тесты на `auto_call_step`:

- рост счётчика при отсутствии кола → `Start`;
- кол активен, тишина 15 минут → `End`;
- `paused = true` + новая речь → ничего (ручной стоп держится);
- `paused = true` + 15 минут тишины → пауза снята, следующая речь даёт `Start`;
- кол активен, речь идёт → таймер обнуляется, `End` не выдаётся.

## Границы

- Порог зашит константой, env-тюнинга нет.
- Тик живёт на репейнтах egui; на 15-минутной шкале задержка кадра неважна.
- При `HEALTH_TRANSCRIBE=0` счётчик не растёт — авто-режим молчит, кнопка
  работает как раньше.
