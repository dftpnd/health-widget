# Локальный просмотр склеенных колов в браузере

## Задача

Кнопка в виджете поднимает локальный HTTP-сервер, открывает вкладку браузера
со списком склеенных колов. Клик по колу — видео играет тут же, родным
`<video>`, без плагинов и внешних библиотек.

## Контекст

Колы лежат в `~/.local/share/health-widget/calls/<id>/`. Склейка (`src/mux.rs`,
кнопка «🎬 Склеить») кладёт туда `combined.mp4`: видео `libx264` + `yuv420p`,
звук `aac`, контейнер mp4. Это ровно то, что Chrome и Firefox играют нативно —
транскодирование на лету не нужно.

Метаданные колов — в SQLite (`transcript_log.rs`): таблица `calls(id, name,
started_at, ended_at)`.

В `src/webmic.rs` уже живёт HTTPS-сервер на vendored `tiny_http` (порт 8787,
токен в URL) — берём оттуда форму, но не сам сервер: webmic слушает внешний
интерфейс ради телефона, записи созвонов туда попадать не должны.

## Поведение

Кнопка **«📺 Колы»** в секции «🎤 Кол», рядом с «🎬 Склеить».

По клику: если сервер ещё не поднят — поднять на `127.0.0.1:8788` в фоновом
потоке (живёт до конца процесса виджета); затем в любом случае
`xdg-open http://127.0.0.1:8788/`. Повторный клик сервер не пересоздаёт.

Порт занят чужим процессом → статус `✖ порт 8788 занят`, вкладка не
открывается.

Транспорт — чистый HTTP на loopback, без токена. Снаружи машины не виден.

## HTTP

| Маршрут | Ответ |
|---|---|
| `GET /` | HTML страницы (`include_str!`), `text/html; charset=utf-8` |
| `GET /api/calls` | JSON-массив колов, `application/json` |
| `GET /video/<id>` | `combined.mp4` с поддержкой Range |
| прочее | 404 |

### `/api/calls`

```json
[{"id":12,"name":"Скрининг Ozon","started":"2026-07-23 14:05:11",
  "ended":"2026-07-23 14:51:02","size":50331648}]
```

Источник — таблица `calls`, отфильтрованная по наличию непустого
`calls/<id>/combined.mp4`. Числовая папка с непустым `combined.mp4`, но без
строки в БД, тоже попадает в список — с `name = "#<id>"` и пустыми временами,
чтобы старые колы не потерялись. Сортировка — по `id` убывающе (свежие сверху).

`size` — байты файла. Длительность на сервере не считаем (не тянуть ffprobe в
запрос) — её покажет сам плеер.

### `/video/<id>`

`id` парсится как `i64`; путь собирается из числа, ни один байт URL в путь не
попадает — этим и закрывается path traversal. Файла нет → 404.

Всегда отдаём `Content-Type: video/mp4` и `Accept-Ranges: bytes`.

В vendored `tiny_http` обработки Range нет — делаем руками, иначе Chrome не
даст перемотку и потянет файл целиком:

- Заголовка `Range` нет → 200, `Response::from_file`, весь файл.
- `Range: bytes=N-M` (и формы `bytes=N-`, `bytes=-N`) → `seek(N)` +
  `Response::new(206, [Content-Range, Content-Length], file.take(len), Some(len), None)`,
  заголовок `Content-Range: bytes N-M/<total>`.
- Диапазон не парсится или начало за пределами файла → 416.

## Страница

`src/calls_web.html` — один самодостаточный файл: HTML, CSS и JS внутри.
Никакого билд-шага (vite обслуживает только webmic) и никаких CDN.

Тёмная тема в тон виджету, системный шрифт. Слева колонка со списком:
`#12 · Скрининг Ozon`, под ней дата-время начала и размер (`48 МБ`). Справа —
`<video controls preload="metadata">` на всю оставшуюся ширину.

Клик по строке: `video.src = '/video/' + id`, `video.play()`, строка
подсвечивается как активная. Перемотка, громкость, скорость, полноэкранный
режим — родные браузерные контролы, своих не пишем.

Пустой список → «нечего смотреть — склей колы кнопкой 🎬 в виджете».

Аудио-only кол (склеен без видео) играет как чёрный прямоугольник со звуком —
это ожидаемо, отдельно не обрабатываем.

## Код

Новый модуль `src/calls_web.rs`:

```
pub enum WebStatus { Idle, Running, Failed(String) }

pub fn open(status: Arc<Mutex<WebStatus>>)
fn serve_loop(server: tiny_http::Server)
fn call_rows(calls_dir: &Path) -> Vec<Row>
fn respond_video(req: tiny_http::Request, path: &Path)
fn parse_range(header: &str, len: u64) -> Option<(u64, u64)>
```

`src/main.rs`: `mod calls_web;`, поле `calls_web: Arc<Mutex<calls_web::WebStatus>>`,
кнопка и строка статуса в `draw_call`.

Строка статуса: `Running` → `▶ 127.0.0.1:8788` (зелёный), `Failed(e)` → `✖ e`
(красный), `Idle` → ничего.

Ограничения проекта: без комментариев в коде; строки UI по-русски; ветка
`master`; шеллим готовые CLI вместо новых зависимостей (`xdg-open`).

## Тесты

Юнит-тесты по образцу `mux.rs`:

- `parse_range`: `bytes=0-499` → `(0, 499)`; `bytes=500-` → до конца файла;
  `bytes=-500` → хвост; мусор → `None`; начало за пределами файла → `None`.
- `call_rows` на `tempdir`: папка с непустым `combined.mp4` попадает; папка с
  пустым `combined.mp4` и папка без него — нет; папка без записи в БД получает
  имя `#<id>`.

Живое воспроизведение и перемотку (206-ответы) проверяем руками в браузере.

## Вне рамок

- Транскрипт на странице и seek по репликам.
- Скачивание файлов, переключение отдельных дорожек `mic`/`zoom`.
- Удаление и переименование колов из веба.
- Запуск склейки из веба — это кнопка в виджете.
- Авторизация, HTTPS, доступ с телефона или из LAN.
